# Dataset image sources and attribution

This file records the Roboflow Universe projects credited as sources of images used to build the Urban Disaster Monitor dataset. The credited names identify the projects and the people or profiles that published them; they do not claim that this repository's authors created the original images.

The [released Urban Disaster Monitor dataset](https://universe.roboflow.com/ufrnprojects-xlut9/urban-disaster-monitor) is marked [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The source projects below displayed the same license label when their pages were reviewed on **7 September 2026**. Check each source page and the original image's terms before reusing third-party content; the compiled dataset's license does not replace those terms.

Selected source images were annotated for this project's classes, preprocessed, and sometimes augmented. Detection examples also add bounding boxes, class labels, and confidence scores. These changes do not imply endorsement by the credited publishers. Synthetic images generated for this project are separate from the third-party sources listed here.

This source list does not map individual files to source projects. The dataset also includes images found through Wikimedia Commons, Flickr, and Google Images; this list does not identify or credit those individual images. Google Images is a search tool, not an image licensor. Where an image-level attribution is needed, consult the original image page and record its author, URL, license, and any modifications.
